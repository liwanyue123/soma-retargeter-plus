# my_data2 — Motion Capture Dataset

This folder contains raw motion capture data in BVH format and their pre-converted NPZ archives.

## BVH Format Notes

| Property | Value |
|----------|-------|
| Coordinate system | **Y-up** (standard Mujoco/Maya BVH) |
| Position unit | centimetres (cm) — standard BVH |
| Frame rate | 180 FPS (`Frame Time: 0.005556`) |
| Root channels | `Xposition Yposition Zposition Zrotation Xrotation Yrotation` |

> **Difference from `my_data`**: `my_data` uses a Z-up (Newton) coordinate system
> with a non-standard scale (requires `position_scale=3.16`). `my_data2` is a
> standard Y-up centimetre BVH — no extra scale is needed.

## NPZ Format

Each `.npz` file was generated by `tools/bvh_to_npz.py` and contains the
following arrays:

| Key | Shape | dtype | Description |
|-----|-------|-------|-------------|
| `joint_names` | `(J,)` | `object` (str) | Joint name for index `j` |
| `parent_indices` | `(J,)` | `int32` | Parent joint index; `-1` for the root |
| `fps` | scalar | `float32` | Frames per second (180.0) |
| `num_frames` | scalar | `int32` | Total frame count |
| `local_transforms` | `(F, J, 7)` | `float32` | Per-frame **local** joint transforms |
| `ref_local_transforms` | `(J, 7)` | `float32` | Reference (T-pose) local transforms |

`J` = 51 joints, `F` = number of frames.

The 7-element transform layout is: **`[px, py, pz, qx, qy, qz, qw]`**
- `px, py, pz` — local translation in **metres**
- `qx, qy, qz, qw` — local rotation as a unit quaternion (XYZW)

### Example: load and inspect

```python
import numpy as np

data = np.load("kuazhangaiwu_02_take_001_A.npz", allow_pickle=True)

joint_names = data["joint_names"]          # list of 51 joint names
parent_idx  = data["parent_indices"]       # (51,) int32
fps         = float(data["fps"])           # 180.0
local_tf    = data["local_transforms"]     # (1922, 51, 7)
ref_tf      = data["ref_local_transforms"] # (51, 7)

# Root position over time (in metres)
root_pos = local_tf[:, 0, :3]             # (1922, 3)

# Rotation of joint 0 (Hips) at frame 0 as quaternion [x,y,z,w]
hips_quat_frame0 = local_tf[0, 0, 3:]
```

## Retargeting with soma-retargeter-plus

Use `--data mydata2` to retarget these clips to any supported robot:

```bash
# Interactive viewer (adam_lite example)
python app/bvh_to_csv_converter.py \
    --config assets/adam_lite_bvh_to_csv_converter_config.json \
    --viewer gl \
    --data mydata2

# Batch export to CSV
python app/bvh_to_csv_converter.py \
    --config assets/adam_lite_bvh_to_csv_converter_config.json \
    --data mydata2
```

Config files for all 5 robots live at:
```
soma_retargeter/configs/<robot>/mydata2/
    mydata2_to_<robot>_retargeter_config.json
    mydata2_to_<robot>_scaler_config.json
    mydata2_to_<robot>_offsets_config.json
```

> **First use**: run the in-app **Calibration** panel to compute
> `joint_scales` and `joint_offsets` for your specific robot before
> exporting CSV/NPZ.

## Re-generating the NPZ files

```bash
python tools/bvh_to_npz.py dataset/my_data2/*.bvh
```

Options:
- `--position_scale FLOAT` — extra scale on top of ×0.01 cm→m (default: `1.0`)
- `--recenter_xy` — zero out the root's XZ offset at frame 0
- `--out PATH` — custom output path (single file only)
